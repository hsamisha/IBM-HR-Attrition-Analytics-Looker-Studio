# IBM HR Attrition Analytics Dashboard Looker Studio

## Project Overview

The **IBM HR Attrition Analytics Dashboard** is an interactive HR analytics project developed using **Looker Studio** and **Microsoft Excel**.

The project analyzes employee demographics, job-related characteristics, compensation, satisfaction levels, work conditions, and employee attrition. The analysis is presented through an interactive dashboard containing KPIs, charts, filters, and multiple analytical pages.

The main purpose of this project is to transform employee data into meaningful HR insights that can support better understanding of workforce and attrition patterns.


## Objective

The objectives of this project are to:

- Analyze employee demographics and workforce characteristics.
- Understand employee attrition patterns.
- Examine attrition across departments, job roles, and employee groups.
- Analyze the relationship between attrition and overtime.
- Analyze job satisfaction, environment satisfaction, and job involvement.
- Examine employee income and job-level patterns.
- Analyze business travel and its relationship with attrition.
- Present HR metrics through an interactive dashboard.
- Generate meaningful insights that can support HR decision-making.

## Dataset Description

The project uses the **IBM HR Analytics Employee Attrition & Performance dataset**.

The dataset contains employee-level information related to:

- Employee demographics

- Department

- Monthly income
- Overtime
- Business travel
- Job satisfaction
- Environment satisfaction
- Job involvement
- Years at company
- Attrition status

The dataset provides information required to analyze employee characteristics and identify patterns associated with employee attrition.

## Approach / Methodology

The project was completed through the following steps:

### 1. Data Collection

The IBM HR employee dataset was collected and loaded into Microsoft Excel.

### 2. Data Preparation

The dataset was reviewed and prepared for analysis by checking:

- Missing values
- Data types
- Duplicate records
- Categorical variables
- Numerical variables
- Attrition-related fields

### 3. Exploratory Data Analysis

The employee dataset was analyzed to understand:

- Employee demographics
- Department distribution
- Job roles
- Income patterns
- Job levels
- Satisfaction levels
- Overtime
- Business travel
- Employee attrition

### 4. Dashboard Development

The prepared dataset was connected to Looker Studio and used to create an interactive HR analytics dashboard.

The dashboard contains:

- KPI cards
- Bar charts
- Comparison charts
- Attrition analysis
- Employee analysis
- Interactive filters
- Summary insights

### 5. Insight Generation

The analysis was used to identify important workforce patterns and factors associated with employee attrition.
